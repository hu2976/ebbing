# 退潮 · 路演 deck 设计 spec

## 是什么
「退潮」的路演 HTML deck。参照 https://cgm.hoka-marathon-by-keepace.asia/ 的**架构**
（不是它的视觉——那是 Keep 绿 + 蓝的浅色企业风，和退潮的产品语言相反）。

## 受众与场景
女性黑客松评委，四分钟，一场看二十几个项目。目标不是让他们听懂产品，
是让他们**在某一刻被卷进去**，散场后能用一句话复述给别人。
投屏距离约 3-5m → 正文 ≥18px，关键数字要大到最后一排能读。

## 参照架构（从参考站拆出来的叙事骨架）
1. 封面
2. **先教会评委读这件事**（参考站用 5 屏讲 TIR/AGP/CV）→ 退潮这里是「凌晨三点那一刻发生了什么」
3. 指出缺口：现有的很完善，缺的是某一层
4. 凭什么是我们：独有资产
5. 一句产品主张（参考站：「不是一个聊天框，是挂在七个时刻上的七个动作」）
6. 方法论
7. 分场景落地
8. 证据（参考站：39 篇文献都经原始记录核验）
9. 一个技术观点
10. Demo

技术架构同样照搬：单文件 HTML + `scroll-snap-type:y mandatory` 全屏翻页
+ 固定顶栏页码 + `.slide.active .reveal` 入场 + `@media print` 直接出 PDF。

## 内容要点（全部来自 03-路演-PRD与四分钟脚本.html，不新编）
- **钩子**：凌晨三点，热线是开着的——但打过去，就有一个人知道了。越是看起来没问题的人，
  越不能让人知道自己有问题。此刻唯一开着又不需要她开口的，是热量 App，而它只会让事情更糟。
- **坐实**：Levinson 2017，105 名确诊患者约 75% 在用 MyFitnessPal，其中 73% 认为它加重了病情。
- **论点一**：要解的不是有效性是留存。Linardon 2024 RCT n=576，暴食发作发生率比 0.69；
  但 6 周脱落 48%，仅 1/3 完成最后模块。行业平均留存 5.5 天。
- **论点二**：躯体那一层是空的。水潴留被读成变胖、停止催吐后反跳性水肿被读成"停了就胖"。
  竞品调研 30+ 产品，Juniver 覆盖清除型贪食却零字提电解质，消费级产品里无一处理。
- **论点三**：暴食是最大也最不被看见的一群。Hudson 2007 女性终生患病率 BED 3.5% >
  BN 1.5% + AN 0.9%；中国 BN 年龄标化患病率约为 AN 两倍（GBD 2019：75.21 vs 38.08/10万）。
- **产品主张**：这个产品里没有人。无账号、无咨询师、无用户互动。
  求助之所以难，是因为求助这个动作本身就是暴露。
- **竞品的准确说法**：急性期入口已被占（Unbinge「2am 在厨房」、URGR panic button、
  UrgeFree 两分钟流程），但**它们都停在冲动退下去为止**。
- **机制**：孤独是中介变量（Southward 2013, n=107，反向路径不成立）→ 零发言小组不是
  退而求其次的社交，是在不暴露任何人的前提下对孤独下手。
- **为什么不做生成式对话**：Tessa 2023 一周下架；Pucci 2026 arXiv:2606.02444，
  临床标注 268 对里仅 44.7% 安全。
- **商业化**：患者端永远免费不做广告不做数据；收入来自不脆弱的那一侧（机构授权）；
  刻意停在医疗器械边界之外所以现在就能跑。
- **披露**：一句，平着说，然后停住。不声泪俱下。

## 视觉约束
- 退潮的产品 token 已冻结：底 #171310 / 纸 #F4EDE3 / 黄铜 #C9A063 / 青玉 #8CC1AA /
  陶土 #CB7E62 / 次级 #968979。deck 可以不照搬，但产品截图一定是这套。
- ⚠️ 不要红色警示、不要绿色奖励（产品自己的铁律，deck 上出现会自相矛盾）。
- ⚠️ 不要进度条、不要百分比环、不要打卡格——产品明确砍掉的东西不能出现在讲它的 deck 上。
- 一个字都不许出现临床词（症状/患者/病人/疾病/治疗/康复/诊断）在**引用产品文案**的位置；
  deck 自己的叙述层可以用（那是对评委说话，不是对用户）。

## 输出格式
单文件 HTML，slide 尺寸按视口全屏（不是固定 1920×1080——参考站就是响应式全屏）。
三版初稿各出 2 屏：① 开场 ② 「留存不是有效性」那条论点页。
截图统一 1600×1000。
