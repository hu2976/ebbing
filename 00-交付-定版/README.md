2026-08-29。三样东西各一个文件夹，互不依赖。

## 01-小程序 —— 定版代码

微信开发者工具 →「导入项目」→ 选 `01-小程序` 这个目录，即可运行。

- 62 屏可跑，构建期自检全绿
- 数据全部存在手机本地，不出设备
- 主包 947K / 1500K

**唯一需要手动配的一处**：`cloudfunctions/talk`（四个人开口说话那一层）读的是云开发环境变量
`OPENROUTER_KEY`。要在云开发控制台 → 云函数 → talk → 环境变量里填上，并上传部署。
**不配也不会崩**——`app.js` 里云开发初始化失败会退回 `data/mentor.js` 里人写好的兜底语料，
产品照常能演完 62 屏。

自检脚本在 `.sync-mp/`（隐藏目录）：
- `node .sync-mp/chk.mjs` 全量自检（死链 / 块型覆盖 / 患者端临床词 / 文案硬规则）
- `node .sync-mp/shot.mjs --all` 逐屏渲染并报「一屏装不装下」

### 另一支：一个晚上，两端

- `退潮-双端.mp4` —— **约 90 秒**。两台手机并排，走同一条时间线：
  21:30 她看今天的滋味、他读今天这一条 → 22:10 他看见垃圾桶，翻开那张卡 →
  23:40 她点「我现在不太好」→ 03:00 她正在吃，屏上「还有 12 个人」→
  03:05 同一时刻他在读「梗犬」那张 → 第二天早上各自一条。
  收在一句：**两端都做。而且互相看不见。**
- `退潮-双端.html` —— 同一支的可交互版本，双击打开自己会跑

这支的重点是「**他们从来不同时在线**」：谁没在用，谁那台就暗下去。
双端硬隔离这件事，画面比文案说得清楚。

**HTML 里可以点的地方**：
- 屏 03　三行选项，点一行翻出它的代价
- 屏 10　四个人的对话演示，自动循环播放
- 屏 10-14、17-18　右边的手机，点进去能一路走
